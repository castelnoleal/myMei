# Mei

Mei is an independent AI agent platform derived from the Agent Zero open-source project.

## Identity

**Mei** is the product name used by this repository and by the MEIOCG ecosystem.

Current public endpoint:

- https://realizer.meiocg.org

## Project direction

Mei keeps the powerful agent, browser, desktop, memory, tools, skills, plugins, projects, and multi-agent foundations of the upstream project while adding MEIOCG-specific identity, integrations, workflows, and product capabilities.

## Upstream

Original project: https://github.com/agent0ai/agent-zero

The upstream MIT license and required copyright notice are retained in `LICENSE`.

## Roadmap

- Mei branding and user-facing identity
- Mei-specific system prompts and defaults
- Realizer integration
- stronger autonomous planning and verification loops
- MEIOCG project and tool integrations
- product-specific UI and deployment configuration
